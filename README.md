## 👨‍💻 About Me

I'm a **Cloud DevOps Engineer** with a strong foundation in automation, infrastructure as code, and secure software delivery. My passion lies in designing and implementing robust CI/CD pipelines, hardening cloud infrastructures, and automating deployment workflows to accelerate software delivery while maintaining security and reliability.

Currently pursuing **Ingénierie des systèmes ubiquitaires et distribués – Cloud et IoT** at **Institut Nationale des Postes et Télécommunications (INPT)** in Rabat, Morocco.

My core focus:
- **DevSecOps**: Building secure pipelines with SonarQube, Gitleaks, OWASP ZAP, DefectDojo
- **CI/CD Automation**: GitLab CI/CD, Jenkins, GitHub Actions with multi-stage security validation
- **Infrastructure as Code**: Terraform, CloudFormation, Ansible for reproducible infrastructure
- **Cloud Platforms**: AWS (Elastic Beanstalk, RDS, ElastiCache, Lambda), Azure, Google Cloud
- **Containerization & Orchestration**: Docker, Kubernetes, ArgoCD for secure deployments
- **Observability & Monitoring**: Prometheus, Grafana, Loki for comprehensive monitoring

I believe in **shift-left security** — integrating security checks early in the development lifecycle — and building platforms that enable teams to deploy fast, securely, and reliably.
